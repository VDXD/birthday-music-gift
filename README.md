# Birthday Music Gift — Romantic UI

This build preserves your sketch's layout while adding a more polished romantic UI:
- Opening page is message-only.
- Seven song pages: large letter area left; poster and compact music player right.
- Side navigation and page count.
- Poster-inspired theme colors per song.
- Responsive design.

Customize `openingMessage` and the seven song objects in `script.js`.
Add covers to `assets/covers/song-1.jpg` … `song-7.jpg` and MP3s to `assets/songs/song-1.mp3` … `song-7.mp3`.
Use VS Code Live Server to preview. Deploy the complete folder to Netlify Drop: https://app.netlify.com/drop
